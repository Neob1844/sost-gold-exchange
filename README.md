# sost-gold-exchange — ABANDONED (archived 16 November 2026)

**This project was abandoned. It is not part of the SOST protocol and no SOST ↔ gold exchange platform is operating.**

- SOST has **no gold backing**, **no committed reserves** and **no obligation to acquire, hold or contribute gold, XAUT or PAXG**.
- There is **no convertibility, redemption right or guarantee** linked to gold or to any external asset.
- Documents in this repository (Model A/B positions, mainnet runbooks, pilot checklists, "gold-backed" positions) describe abandoned plans and test material. None of it is in force.
- Do not send funds to any address or contract mentioned here.

The current SOST model is Proof of Work + DTD and DTD Jackpot, which distribute SOST itself (V16, active: 50% miner / 50% DTD). See https://github.com/Neob1844/sost-core and https://sostcore.com/sost-whitepaper.html.

This repository is archived (read-only) and kept only as a historical record.
